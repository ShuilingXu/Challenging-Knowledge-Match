# 母活动、答题与摇奖流程

## 组织一场新活动

1. 创建母活动。在母活动设置会场、报名字段和人员权限，启用报名。用户只在母活动登记一次。
2. 在活动管理的母活动行添加「答题子活动」与「摇奖子活动」。母活动总览也提供环节入口。
3. 为答题子活动设置题库、题组、普通答题或抢答模式，以及计分规则。
4. 为摇奖子活动配置摇奖奖池、库存和最低总积分。排名奖池放在答题环节。
5. 开始母活动及对应子活动。答题控场负责开题、倒计时、判题和积分；摇奖控场负责开始摇奖、停止并公布中奖人。

母活动菜单以管理为主；答题子活动显示题库和答题控场；摇奖子活动显示摇奖控场及自助抽奖与核销。活动切换列表按母活动和子活动排列。

## 人员与积分

新答题子活动和摇奖子活动共用母活动的人员、会场和报名字段。母活动身份可以直接进入所属答题与摇奖环节，不能跨其他母活动，也不能访问主持人的答案或名单接口。

答题子活动的排行榜使用本环节积分流水汇总；母活动总积分是同一参与者在共享环节及母活动兼容业务中的累积得分。摇奖子活动用母活动总积分判断资格。改分、改判以差额调整总积分和环节积分，不重复计分。人员及得分变更实时通知母活动及共享环节。

抢答模式中，用户端开题后只有抢答按钮。主持人看到标准答案和抢答顺序，现场组织回答后点击判对或判错。用户端实时显示判题得分。

## 主持人摇奖与自助抽奖

主持人摇奖入口是「摇奖子活动 → 摇奖控场」。选择奖池后开始滚动，点击「停止并公布中奖人」由服务器随机抽取符合条件、状态正常且未在该奖池获奖的人，扣减库存并生成领奖记录。重复确认同一次请求只返回原中奖结果。所有当前可用参与者在主持人摇奖中等概率选择。

主持人摇奖不消耗用户的自助抽奖次数。自助抽奖保留在「自助抽奖与核销 → 奖池 → 抽奖入口」，工作人员授予次数，用户扫码自行抽奖；自助抽奖沿用原有次数和奖池权重规则。

题目与中奖结果同步到子活动设备及母活动设备。核销仍通过已有奖品记录完成。

## 状态规则

- 草稿不能报名、答题或摇奖；先启用报名，再开始对应环节。
- 答题、抢答和摇奖要求子活动处于进行中，母活动处于报名中或进行中。
- 母活动暂停时，进行中的子活动同步暂停，题目与倒计时关闭。
- 恢复母活动不会自动恢复子活动的旧倒计时；工作人员恢复子活动并重新开题。
- 母活动结束或终止时，同步关闭已有子活动。
- 已有人员、题目、积分或奖池的活动，不能改类型或换母活动。

## 旧数据兼容

旧母活动已有题目或奖池时，保留标记为「原有答题控场」等兼容入口。新环节应添加为子活动。

旧答题子活动已有独立人员或会场时，保留独立报名、身份、积分与记录，并在母活动总览标明旧版模式；不会按联系方式自动合并人员或把历史积分转入母活动。没有独立人员或会场的空答题活动可安全共用母活动名单。数据库迁移不删除人员、题目、积分或中奖记录。

普通答题与抢答都保持每人每题一次的记录语义。同一题重新开题保留原记录；新一轮比赛应使用新的题目或答题环节。
