# 抢答模式

在活动的新增或编辑窗口中，将「答题模式」设为「抢答模式」并保存。开题期间不能切换模式，请先揭晓答案或回到候场。

- 主持人在实时控场台选择题目并开题，参与端显示题目与抢答按钮，不显示答题选项或答案输入框。
- 抢答按钮只在题目开放、倒计时未结束且活动未暂停或结束时可用。成功后显示本题抢答名次。
- 主持人可以查看标准答案（含答案媒体），以及按抢答顺序排列的姓名、场次和时间。名单通过现有 WebSocket 通道实时刷新，断线重连后重新读取，并有轮询兜底。
- 顺序以服务器取得数据库锁的顺序为准。同一参与者每题只记录一次，重复点击或网络重试返回原名次；刷新页面保留记录。同一题重新开题仍保留原名单。
- 抢答成功后先登记顺序。主持人现场组织回答，在控场台点击「判对并计分」或「判错并计分」，按该环节的计分规则计算得分；再次判题只调整差额，不重复加分。用户端实时显示判题得分。
- 用户只能查询自己的抢答记录，完整名单和标准答案仅在主持人端展示。

数据库迁移 `V20__buzzer_mode.sql` 为现有活动设置默认普通答题模式，添加持久化抢答记录。应用部署后由 Flyway 自动执行。

新活动的抢答模式在答题子活动中配置，母活动统一报名。活动须开始后才能开题；母活动暂停时子活动同步暂停并关闭当前题目。完整流程见 `ACTIVITY-WORKFLOW.md`。
