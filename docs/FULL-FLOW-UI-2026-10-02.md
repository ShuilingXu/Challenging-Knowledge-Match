## 已修复的问题

| 问题 | 修改与复测 |
| --- | --- |
| 大屏模板网格留白、内容超出可视区 | 按可见组件数量设置列数；画布适配窗口高度；字号、二维码和间距跟随画布尺寸 |
| 获奖名单换行错位、兑换文字竖排 | 将姓名、会场和奖品组合为一个单元格，恢复四列布局 |
| 竖图与选项挤占布局 | 图片使用 contain 保持比例；桌面端媒体与选项分列；长选项正常换行 |
| 提交数量、结果卡片对比度不足 | 统一浅色卡片与文字颜色，修正统计区字号和换行 |
| 移动后台菜单无法点击 | 隐藏侧栏停止接收点击；装饰层不拦截事件，390px 宽度成功打开并进入设置 |
| 答题端页脚位置与样式不一致 | 页脚独立放在主布局末尾，普通文本直接渲染；移动端收紧顶部装饰区 |
| 加载页大片空白、配对和错误页面风格不一致 | 居中加载图标和提示，统一浅色主题 |
| 总览显示固定城市、静态倒计时和错误阶段 | 使用真实城市、剩余时间和活动生命周期；结束后保留积分记录提示 |
| 暂停或结束后仍显示可开题 | 控场禁用开题、下一题、跳题操作；倒计时到零明确显示截止 |
| 成功重载后残留错误提示 | 数据成功加载时清除旧错误 |
| 远程 WebSocket 开发代理主机名异常 | 为 /ws 设置 changeOrigin，修复本地联调的主机头问题 |
