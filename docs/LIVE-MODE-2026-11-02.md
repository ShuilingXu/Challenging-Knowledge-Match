# 现场操作简化（第一轮）

本轮修改本地前端，未部署。沿用现有服务端接口、计分和活动状态规则。

## 工作人员入口

进入会场后默认显示现场首页。答题、海龟汤、抽奖可从上方直接切换。
左侧常驻现场控制、签到检票、发奖核销；题库、人员、大屏、权限等入口收进“活动准备与更多操作”。
原有管理页面与链接保留。顶部合并为一个活动/会场选择器。

## 答题

1. 在“题组与答题时长”中检查题组和时长，默认 30 秒。
2. 开始或恢复活动，检查题目预览，点击“开始本题”。
3. 计时结束后点击“公布答案”。提前结束会先确认，并立即公布答案。
4. 点击“准备下一题”只切换主持人预览，观众大屏保留当前内容；再次点击“开始本题”才开题计时。
5. 最后一题完成后展示积分榜。重开、积分榜、确认获奖在“更多控场操作”中。

当前接口没有独立收题阶段，因此本轮提前收题与公布答案仍是一个操作。作答中禁止切换预览题目；其他主持端开题时跟随实际发布题目。

## 海龟汤

开始环节后，主操作依次为展示汤面、公开下一条未公开线索、揭晓汤底。
仍可在下方线索板自由选择任意线索，或提前揭晓汤底。揭晓前需要确认。
翻页、调速、重置、临时添加线索收进折叠区域；未开始时自动展开环节状态，便于开场。

## 验证与后续

前端测试与生产构建通过；浏览器交互、真实服务端及投影设备联调仍待完成。
本轮尚未加入可排序节目单、PPT导入抢答、单会场快速创建，也未改变暂停的服务端行为。
