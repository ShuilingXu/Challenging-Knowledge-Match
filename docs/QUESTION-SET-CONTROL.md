# 题组启用与控场选组

管理员在题库中编排题组，并管理题组是否启用。启用多个题组不会自动切换当前使用的题组，题库中不再提供下发操作。

主持人在答题控场的“使用题组”中选择管理员已启用的题组。选组后，控场题目、参与端题目与受控大屏同步更新，并返回等待状态。题组内仍只使用已启用的题目，按题组保存的顺序出题。

答题开放期间不能切换题组，须先结束当前题目。管理员停用当前使用的题组时，会取消选组并回到等待状态，停止当前答题。

主持人可以查看题组、选择使用题组，但不能新建、编辑、删除、同步题组或修改启用状态。权限仅限主持人所属会场。

升级时已有题组默认启用，并保留原先选中的题组。新建或新同步的题组默认启用，但不会自动成为当前题组。尚未选择题组时，沿用全部已启用题目的出题方式。
