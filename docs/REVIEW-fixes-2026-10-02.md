第 26 条的子项：

- 人工评分限制在 0 至题目满分，前端与后端都校验。
- 评分后保存 CORRECT/PARTIAL/INCORRECT，历史 SCORED 在 V18 转换，统计不再漏计。
- 答题响应显示实际参与计分的 responseRank。
- 单次、批量核销都使用认证工作人员身份记录操作人。
- 缺失或不合法 JWT 声明返回 401；匿名访问 /auth/me 返回 401。
- 参与者访问限制为本人活动与明确允许共享的抽奖子活动；不能跨分会场读取题目、积分榜或控制状态。
- 损坏的评分规则和答案 JSON 明确报错；是否按 JSON 解码答案由题型决定，选项以 `[` 开头不再误判。
- 注册与会场容量调整锁定活动，防止并发超额登记；容量不能低于已登记人数。
- 同一活动跨会场重复联系方式被拒绝；已有重复登记不自动合并身份。
- 保留保障答题顺序的短事务题目锁；屏幕计数移至提交后独立事务，Redis 发布在提交之后。屏幕状态读取会核对实际提交数。
- 服务端禁止删除预设模板，并能恢复缺失预设。
- 上传校验实际文件特征与声明类型，拒绝 SVG 和不支持的格式；媒体响应使用 nosniff 和 sandbox。
- 同源媒体读取不暴露有期限的预签名 URL，支持音视频单区间 Range 请求。
- 定期清理过期刷新令牌、撤销记录、设备/参与者凭据、验证码和限流记录。

## 升级要求

1. 升级前备份数据库，并保留原服务环境文件。使用 Flyway V15–V19 升级，不要手工修改已应用的旧迁移。
2. 配置足够随机的 JWT_SECRET、APP_BOOTSTRAP_PASSWORD 和对象存储凭据。更改 bootstrap 环境变量不会重置已存在账号的密码；历史默认密码账号须由管理员修改。
3. V18 使用修正流水恢复历史积分；已经发放或核销的奖品不会自动撤销，需根据纠正后的积分榜人工复核。
4. 旧参与者/大屏会话不含新续期凭据，升级后首次需要重新登录或配对。新会话随后自动续期。
5. 人机验证不证明手机号所有权。这是本次按用户要求采用的验证范围，没有添加身份第二因子。
