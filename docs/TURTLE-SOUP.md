# 海龟汤子活动

海龟汤是仅供现场大屏使用的子活动，不提供参与者报名、手机作答、计分或抽奖入口。每个子活动保存一份汤稿；需要换故事时，先回到候场，再编辑汤稿，或新建另一个海龟汤子活动。

## 操作流程

1. 在「活动管理」中点击母活动旁的「添加海龟汤子活动」，填写名称并选择母活动。
2. 进入「海龟汤控场」，填写故事标题、汤面、汤底，可添加最多 50 条线索。每条线索独立填写，主持人可以任意选择公开顺序。
3. 保存汤稿。启用母活动后，直接开始海龟汤环节，无需启用报名。
4. 在母活动或本环节的「大屏管理」完成设备配对。本环节新注册的设备会直接取得当前展示状态；新加入的母活动设备可点击「同步当前展示」。
5. 点击「展示汤面」，观众现场向主持人提问。主持人在「交互线索板」选择任意卡片的「公开这条线索」，不必连续公开；误操作时点击对应卡片的「撤回这条线索」。大屏按实际公开顺序排列，并保留原线索编号。
6. 点击「揭晓汤底」，再点击「确认揭晓」。无需公开全部线索，也可以揭晓。未公开的线索依旧不会下发。
7. 「回到候场 / 重置」会同时清除大屏上的汤面、线索和汤底。汤稿保留，后续可以重玩或修改。

现场需要补充提示时，使用「临时添加线索」。可「保存为待展示线索」后再从线索板公开，也可「添加并立即公开」。临时线索同样支持单独撤回，重置后保留在汤稿中。每条最多 2000 字，全部线索总数最多 50 条。添加操作与公开选择一起经过版本校验，遇到其他主持人的并发更新时保留输入内容、刷新状态并提示重试。

主持人页左侧是展示控制、交互线索板和临时添加入口，右侧是已公开内容预览。小屏幕采用纵向排列。大屏使用深绿色背景、高对比文字、编号线索卡片和汤底区块，支持现有设备字号及滚动设置。

## 状态与权限

- 管理员负责创建子活动、保存完整汤稿和管理活动状态；继承母活动权限的工作人员可查看私密稿、控制展示和临时添加线索。
- 私密汤稿只通过工作人员接口读取。设备和参与者不能读取该接口；活动通知不包含汤稿正文。
- 大屏数据仅包含已公开的汤面、线索及明确揭晓后的汤底。
- 汤稿与公开状态存入数据库。主持人或大屏刷新、重新连接后恢复已保存状态。
- 控场使用状态版本校验与活动行锁。多人同时操作时，过期指令被拒绝并刷新状态。
- 海龟汤或母活动暂停时回到候场，线索计数归零。恢复后需重新点击展示汤面。
- 推理或揭晓过程中锁定完整汤稿编辑，避免修改已公开故事。推理中可单独追加临时线索；揭晓后需要回到候场再添加。
