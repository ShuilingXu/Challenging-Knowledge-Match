# 自动分页和远程播放验证记录

海龟汤大屏按实际字号和可用高度测量文字，再按完整字符划分阅读页。保留换行、空格和组合表情，尽量在句子末尾分页；各分区显示页码、自动播放状态和进度。新线索按原稿编号定位。短文本只有一页。

暂停、继续、手动翻页、从头播放和速度设置随原有海龟汤 JSON 状态持久化，使用现有控场接口、修订号和会场权限。大屏只能读取已公开内容。手动翻页会暂停，新线索和揭晓会开始新的阅读周期。

不同大小屏幕按各自区域分页，远程上一页和下一页作用于各分区。预览明确提示分页数量以实际大屏为准。低高度屏幕只保留当前重点区域。

本地浏览器已验证：

- 自动翻页有实际页码变化，内容区域不需要手动滚动。
- 下一页后实际大屏暂停；刷新后页码和暂停保持。
- 从头播放从第一页开始；撤回后重新公开第三条线索，显示定位到线索 3。
- 揭晓后三个区域内的当前页文字高度均不超过区域高度。
- 430×932 窄屏整页无溢出，三个内容区文字均完整落在阅读区域内。
- 生产构建在 1280×480 上仅显示汤底，页面尺寸保持 1280×480。
- 长稿测试到 7500 字汤面、8000 字汤底和 2000 字线索。
- 前端 51 项测试通过；后端全量 122 项通过；后续新增焦点断言的海龟汤 7 项测试通过。生产前端和后端构建成功。

同时更新了 8 页简明手册及完整手册。未部署到线上。更新包和后端更新步骤见 `docs/海龟汤自动翻页更新说明.md`。

## 多条线索同屏优化

线索区按实际可用空间组合多条卡片，能放下时静态展示，放不下才独立轮播。单条过长线索分页保留原编号和完整文字；轮播阅读时间自动按内容量安排。线索区不使用大屏播控状态，暂停、手动翻页、调速和从头播放均只影响汤面和汤底。

本次前端 54 项测试通过；本地浏览器验证三条短线索同屏、八条线索溢出分组、汤面暂停时线索自行换页、手动翻页只改变汤面，以及卡片高度不超过显示区域。截图见 screen-clues-together.png 和 screen-clues-overflow.png。
