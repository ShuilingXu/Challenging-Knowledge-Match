## 发现并修复的问题

1. 公共接口隐藏母活动后，会场入口仍按无父级活动筛选，造成选择页空白。改为展示父级未出现在公共列表中的会场，并保留其已开放功能入口。
2. 报名页面只有一个可用会场时仍要求手动选择。现在自动选中并明确显示会场名称；无效的指定会场不会被静默替换。
3. 手机答题页顶部内容过长，导航容易被推到屏幕下方。登记后的顶部信息压缩，底部导航固定，并留出安全间距。
4. 草稿、报名中、暂停和结束状态的开题说明不准确。现在直接说明下一步操作；抽奖也提示奖池、库存和活动状态。
5. 大屏公布答案或倒计时结束后仍提示提交答案。现在根据阶段和时间显示等待公布或等待下一题的说明。
6. 玩家选择器中的功能名重复、个人信息显示内部会场代码。现在使用清楚的会场和功能名称，内部参与人 ID 改为“参与编号”。
7. 玩家无奖励、无抽奖机会时缺少说明。增加奖励出现位置和等待工作人员安排的提示。
